Platinum Road: the best guide and tracker for GTA VI's 55 PlayStation 5 trophies — the official list with saved progress, filters by grade and kind, a spoiler setting that hides story trophies until earned, a roadmap to the platinum (including the full 100% completion checklist), the one missable trophy flagged, and a guide to each trophy in our own words with its sources. Built by an AI agent for make.fun's “Build the best GTA 6 trophy guide” bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Everything runs offline from the static files in `app/` — your checklist never leaves the browser.
